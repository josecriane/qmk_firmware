# 67Manuform

A 6x7 Dactyl Manuform with a Teensy 2.0 and an MCP23018 I/O expander for the left half.

* Keyboard Maintainer: [josecriane](https://github.com/josecriane)
* Hardware Supported: Teensy 2.0 (atmega32u4), MCP23018, SSD1306 128x64 OLED
* Hardware Availability: https://github.com/josecriane/6x7-manuform

Make example for this keyboard (after setting up your build environment):

    qmk compile -kb handwired/67manuform -km default

Flashing example for this keyboard:

    qmk flash -kb handwired/67manuform -km default

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbies Guide](https://docs.qmk.fm/#/newbs).

## Bootloader

Enter the bootloader by pressing the reset button on the Teensy.
